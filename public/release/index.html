Evidence

  • Baseline built and all four class routes ran before changes.
  • Seeded runs: same combat outcome, HP, damage, healing, mana, and end time as v58 on Rend, Patchwerk, Sapphiron.
  • Five specs × desktop 1440px / touch 390px: casting, warning target, reset, saved encounter and width checks.
  • Reduced-motion browser checks; cues are text and static outlines. Existing optional healing audio retained.
  • Engine history capped at 80 entries. Short seeded full-fight samples took roughly 3–18ms before and 3–11ms after; these are smoke measurements, not a benchmark.

Automated checks establish functional behavior, not player learning. No real-phone playtest or independent live Sites verification was available. The uploaded bundle anchors the baseline.

What your feedback changed

You said fights weren't frustrating and wanted telegraphed abilities to anticipate healing. We kept difficulty and timings unchanged, extended readable warnings to existing bosses, and deferred new encounters and extra systems.

Next experiments, in priority order

  1. Test whether players begin a heal before Hateful Strike after seeing the tell. Keep the aid only if anticipation improves without obscuring health bars.
  2. Expand death review with damage-source attribution and incoming-heal timing. First gather pulls where the last-eight-decision report cannot explain a death.
  3. Prototype one final-phase pressure change only if players have mastered existing tells. Label it as an invented practice rule and compare seeded survival and mana curves.
  4. Audit spec mechanics against pinned Forever source before altering class balance. Current data provenance is documented; this batch verifies regression, not every spell against the game.
