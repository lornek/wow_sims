# UI reference artwork

`healbot_ui_ref_001.png` is the original screenshot supplied by the user, moved here from the repository root without changing its bytes. It guides class colors, beveled frame highlights, softer text shadows, and role emblems.

The tank, healer, and crossed-swords emblems in `public/healing/report-icons/role-{tank,healer,dps}.png` are circular, transparent crops of this image. The semantic icon-purpose registry records their uses and alternate selections. Original screenshot and Blizzard artwork retain their original ownership.
